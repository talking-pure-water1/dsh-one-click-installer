# DSH 一键安装器 · 使用说明（给电脑小白）

> 这个文件夹里的东西只有一个目的：**让完全不懂电脑的人，双击一下就能用上 DSH（DeepSeek Harness）。**

---

## 一、怎么用（四步）

1. 把整个 **DSH一键安装** 文件夹解压到任意位置（桌面、D 盘都行，别放回收站就行）。
2. 双击 **`安装DSH（初次使用点击这里就好啦⭐️）.cmd`**。
3. 中途会问你两件事（**懒得改就直接按回车**）：
   - 快捷方式叫什么名字？（默认「DSH Web」）
   - 图标要换吗？（默认鲸鱼图标；想换按 `1`，随后弹出系统文件框让你挑 `.ico`/`.exe`/`.dll`）
4. 等 1~3 分钟。装好后：
   - 自动打开 DSH 的**独立窗口**（无地址栏、无标签栏，像桌面软件）；
   - 桌面出现你命名的快捷方式，以后双击它就能启动；
   - **程序已复制到安装目录，所以这个下载来的工具包文件夹可以删掉了**，快捷方式照样能用。

> 如果系统弹出“Windows 已保护你的电脑 / 未知发布者”，点 **更多信息 → 仍要运行** 即可（这是所有脚本类工具的通用提示，不是病毒）。

**装完第一次用还要做一件事（我们只指路，不代管你的账号）**
进入 DSH 界面后，在设置里填入**你自己的 DeepSeek API Key**：到 <https://platform.deepseek.com> 注册 → 创建 API Key → 复制粘贴到界面里保存。费用和数据都在你自己账号下。
（也可以在开始菜单搜到 **「DSH 控制面板」**，点“去获取 API Key”一键打开开放平台。）

**日常入口**
- 桌面快捷方式 —— 启动 DSH（最常用）
- **右下角任务栏的鲸鱼图标（托盘）** —— 打开界面 / 重启 DSH / **安全退出 DSH（推荐）** / 更新 DSH / 打开控制面板 / 退出托盘（工具包删了也还在）
- 开始菜单 → **「DSH 控制面板」** —— 安装/启动/更新/改名换图标/卸载/看日志，全在按钮上（工具包删了也还在，因为它指向安装目录）
- 如果工具包还在：`启动面板（第二次及以后使用点击这个就好啦❀）.cmd`（面板）、`更新DSH.cmd`、`改名换图标.cmd`、`卸载.cmd`

> ⚠️ **退出请用托盘里的「安全退出 DSH（推荐）」**，不要用任务管理器"结束任务"。
> DSH 的会话是分批写入磁盘的，安全退出会先让它把数据写完再关闭；强杀进程有可能让最后一段记录不完整，重开时出现"历史加载失败"。
> 安全退出的原理：向 DSH 进程发送等价于 Ctrl+C 的信号，等它自己收尾（超时才兜底强制结束，并会记录下来）。

## 一点五、图形控制面板（最省心）

双击 **`启动面板（第二次及以后使用点击这个就好啦❀）.cmd`**，浏览器会打开 `http://127.0.0.1:17800` 这样的本地地址，页面里有：

| 区域 | 能做什么 |
|---|---|
| 环境状态 | Node 版本、DSH 版本、服务是否在跑、程序/数据目录、当前窗口模式（每 4 秒自动刷新） |
| 一键操作 | 安装/修复、启动 DSH、打开 DSH 页面、更新 DSH、卸载、打开数据目录、打开日志目录 |
| 快捷方式 | 填名字 + 选图标（"选择图标…"会弹出系统文件框）→ 点"应用"即刻生效 |
| 行为开关 | 应用模式窗口、关窗即停服务、独立浏览器配置——点一下就切换并写入配置 |
| 日志 | 安装/启动/更新/面板日志直接在页面里看 |

安全说明：面板**只监听本机 127.0.0.1**，不对外开放；端口被占会自动换；关掉面板窗口即停止面板（DSH 服务不受影响）。

## 二、它到底做了什么

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1 | 检查 Node.js | 已有合版本（22.19+ 或 24+）就跳过；没有就自动安装 |
| 2 | 安装 Node.js | 优先用系统自带的 winget（会弹一次授权）；不允许时改用国内镜像的免安装版，**连管理员权限都不用** |
| 3 | 配置 npm | 只补缺：镜像源设为国内 npmmirror；缓存/全局目录若在 C 盘则迁到别的盘 |
| 4 | 安装 DSH | 全局安装，得到稳定的启动命令（不再依赖临时缓存） |
| 5 | 数据位置 | 若你以前用过 DSH（已有 `.dsh` 数据）就**保持不动**；全新机器则放到非 C 盘 |
| 6 | 桌面快捷方式 | 名称可自定义、图标可自选，落在**真实桌面**（兼容 360/OneDrive 搬家过的情况）；自动清理重复图标 |
| 7 | 部署程序副本 | 把程序复制到安装目录（默认 `D:\dsh-launcher\app`），于是**下载来的工具包可以删掉**，快捷方式照常可用 |
| 8 | 启动并等待 | 隐藏窗口启动，轮询到界面真的能打开为止，再开**应用模式窗口**（无地址栏/标签栏，像桌面软件） |
| 9 | 后续维护 | 开始菜单「DSH 控制面板」= 安装/启动/更新/改名换图标/卸载/看日志；`更新DSH.cmd` 升级 DSH 本体 |

**安全与体贴设计**
- 端口被别的程序占用 → 自动换一个空闲端口，不会报错崩溃；
- DSH 已经在运行 → 只打开界面，不会重复启动（避免“地址已被占用”错误）；
- 不会重复安装：再点一次就是“修复模式”，只补缺的东西；
- C 盘紧张时会自动把 Node、缓存、数据放到空间最大的非系统盘；
- 应用模式下会临时关掉插件的自动开页，**只开一个窗口**，不再出现"两个同样的网站"。

## 三、常见问题

**1. 双击后窗口闪一下就不见了？**
说明安装过程出错。打开本文件夹里的 `install.log` 看最后几行；也可以再双击一次 `安装DSH（初次使用点击这里就好啦⭐️）.cmd`（它是幂等的，不会重复装）。

**2. 卡在“下载 Node”很久？**
国内网络问题。关掉重来一次，安装器会重试；也可先手动安装 Node 24 LTS（https://nodejs.org 或 https://npmmirror.com/mirrors/node/），再运行本安装器。

**3. 装完想改快捷方式的名字或图标？**
**双击 `改名换图标.cmd` 就行**（专门为这个场景准备的入口）：
- 先弹输入框让你输入新名字（支持中文，留空则用默认「DSH Web」）；
- 再弹文件选择框挑图标——支持 `.ico`，也能直接选 `.exe` / `.dll`（比如借用某个软件的图标）；
- 确认后在桌面生成/覆盖，并**当场回读**目标、图标、工作目录是否正确。

命令行等价写法（无人值守/批量）：
```
powershell -NoProfile -ExecutionPolicy Bypass -File shortcut.ps1 -Name "我的工作台" -IconPath "D:\图标\a.ico" -Force
```
也可以在装的时候一步到位：`安装DSH（初次使用点击这里就好啦⭐️）.cmd -ShortcutName "我的工作台" -IconPath "D:\图标\a.ico"`

**4. 打开后是一个没有地址栏的独立窗口，能改回普通网页吗？**
默认就是**应用模式**（看起来像桌面软件，这是刻意的）。想改回普通浏览器标签页，有两种办法：
- 临时：运行 `launcher\start-dsh.ps1 -NoAppMode`；
- 永久：把 `launcher\config.json` 里的 `"appMode": true` 改成 `false`。
另外默认**共用你平时的浏览器配置**（界面状态、上次会话都在）；如果想让 DSH 用一套独立干净的浏览器配置，加 `-IsolatedProfile`。

**5. 关掉那个窗口，DSH 会停吗？**
默认**不会**（服务继续在后台跑，双击快捷方式又能打开）。想让"关窗即停服务"，把 `launcher\config.json` 的 `"killHostOnExit"` 改成 `true`，或运行时加 `-KillHostOnExit`。

**6. 怎么升级到新版 DSH？**
三个入口，**删掉下载来的工具包后照样能用**（它们都在安装目录里）：
1. 右下角托盘 → **「更新 DSH」**（推荐，会弹一个进度窗口）；
2. 开始菜单 →「DSH 控制面板」→ 点「更新 DSH」按钮；
3. 工具包还在的话：双击 `更新DSH.cmd`。
更新会显示当前版本、查最新版、执行更新，并问你要不要顺手重启服务让新版生效。

**7. 想让它别每次自动弹浏览器？**
浏览器每次会多开一个标签，是因为 DSH 的 `dsh-web-open` 插件在启动时自动开页。应用模式下启动器会临时关掉它（只开一个窗口）；想让插件彻底静默，可以设环境变量 `DSH_WEB_OPEN=0`（但托盘图标也会一起消失）。

**8. 怎么卸载？**
推荐：开始菜单搜 **「DSH 控制面板」** → 点“卸载”（工具包删了也能用）。
也可以双击工具包里的 `卸载.cmd`。默认只删快捷方式和程序目录，**保留你的历史对话**；要连数据一起删需加参数（脚本里有提示）。你原有的其它快捷方式不会被乱动。

**9. 我把这个下载来的文件夹删了，快捷方式还能用吗？**
**能用（已实测验证）**：安装时会把程序**复制一份到安装目录**（默认 `D:\dsh-launcher\app`），快捷方式指向的是那份副本。我做过一次真机测试——把工具包文件夹改名移走（等同于删除），直接跑快捷方式里那条命令，依然正常启动。
卸载/修复请用开始菜单的「DSH 控制面板」（它也在安装目录里，不依赖工具包）。
> 旧版（2026-09-15 之前打包的）快捷方式指向工具包内部，删了就会失效——重新跑一次新版安装器即可修正。

**10. 反复安装会不会堆出一堆图标？**
不会。安装器会**自动清理指向同一个启动器的其它快捷方式**，只保留你这一次命名的那一个；同时会清理安装目录里改名前的旧入口文件。

**11. 怎么把 DSH 固定到任务栏？**
安装到最后会问一句「要不要固定到任务栏？」。选「要」时：
- 程序会先尝试自动固定；**但 Windows 11 已不允许程序自动固定**，所以通常会自动打开桌面并**选中那个快捷方式**，你只要：右键它 →（Win11 可能要先点「显示更多选项」）→ **固定到任务栏**，一步就好。
- 也可以用命令行参数：`安装DSH.cmd -PinTaskbar`（无人值守时也会给同样的引导）。

**12. 杀毒软件（360 / 电脑管家）报木马怎么办？**
这类"下载并运行脚本"的工具被误报很常见，**不是真病毒**。我们已经尽量降低误报特征：
- ✂️ **删掉了 wscript + .vbs 隐藏启动链**（这是杀软最敏感的行为特征），快捷方式现在直接调用系统自带的 PowerShell；
- 🔌 **托盘图标改成可关**：`launcher\config.json` 里 `"trayIcon": false`（或安装时加 `-NoTrayIcon`）就不会有隐藏的辅助进程；
- 🌐 面板只监听本机 `127.0.0.1`，不对外开放；
- 📦 分发包里不含任何测试脚本、日志、本机配置。
遇到误报时：① 在杀软弹窗里选「允许本次/信任该文件」；② 把安装目录加入白名单；③ 到杀软官网提交**误报申诉**（360：`https://open.360.cn/report`，腾讯电脑管家也有误报申诉入口），把 `install.ps1` 一起上传说明即可。彻底消除提示需要给程序买**代码签名证书**（EV 证书，约 ¥2000+/年），个人分享一般没必要。

**13. 界面里报 `Failed to extract accountId from token` 怎么办？**
这是 **OpenAI Codex / ChatGPT 账号登录（OAuth）** 那条模型通道报的错（来自 DSH 用的 AI SDK `pi-ai`）：它要从登录令牌里读 `chatgpt_account_id` 这个字段，读不到就报这句。常见原因和处理：

| 原因 | 处理 |
|---|---|
| 填的是 **API Key**，却选了需要"ChatGPT 账号登录"的模型（如 gpt-5.x-codex） | 换回 **API Key 方式**的 provider；或干脆用 DeepSeek 官方（推荐） |
| 用的是**第三方中转站**的 key | 中转站令牌里没有该字段，换官方 API 或换一家 |
| ChatGPT 账号的**登录令牌不完整/过期**，或账号类型（团队/企业）不含该字段 | 在设置里**登出后重新完整登录一次**；仍不行就换 provider |
| OAuth 授权范围不足 | 属上游已知问题（社区修复是增强 Codex OAuth scopes），只能等更新或换 provider |

**一句话结论**：想省事就**用 DeepSeek 官方 + 自己的 API Key**，完全不会碰到这个错（我们的默认指引就是这条）。

**14. 怎么配置 API Key？**
我们**不代管**你的账号：进入 DSH 界面后自己填。步骤：<https://platform.deepseek.com> 注册 → 创建 API Key → 复制 → 回到 DSH 界面设置里粘贴保存。面板首页也有「去获取 API Key」按钮。

**15. 我的聊天记录在哪？**
默认在 `C:\Users\<你的用户名>\.dsh`（若安装时设过 `DSH_HOME` 则在那里）。**不要手工删这个文件夹**，否则会丢历史会话。

**16. 安装时提示“无法加载脚本 / running scripts is disabled”？**
正常现象——本工具的 `.cmd` 入口已经内置绕过命令（`-ExecutionPolicy Bypass`），直接双击 `.cmd` 就行，不要去直接运行 `.ps1`。

**17. 面板打不开 / 提示端口被占用？**
换个端口重开即可：`powershell -NoProfile -ExecutionPolicy Bypass -File panel.ps1 -Port 17801`。面板只在本机监听，不会影响 DSH 服务。

**18. 想用「中转站 / API 网关」的 key（不是官方 API），该怎么配？**
中转站（例如 `hk.ccdan.live` 这类"AI API 网关"）本质是 **OpenAI 兼容接口**，配置要点：

| 要填 | 填什么 |
|---|---|
| 协议 / API 类型 | **OpenAI 兼容（`openai-completions`）** —— 千万**不要**选带「ChatGPT 登录 / Codex」字样的通道 |
| Base URL | 站点接入文档里的地址，通常是 `https://域名/v1`（可以先用浏览器打开 `该地址/models` 验证：返回 401 = 接口正常、需要 key） |
| API Key | 该站生成的 key（填进界面表单，别写进配置文件） |
| 模型 | 点"拉取/发现模型"自动列出来，或手填站点给的模型 id |

> ⚠️ 如果把中转站的 key 填到 **Codex / ChatGPT 登录** 那条通道，就会报 `Failed to extract accountId from token`（见第 13 条）——因为那条通道只认 ChatGPT 账号的 OAuth 令牌。
> 另外：Claude 系模型若该站只提供 Anthropic 协议，要把协议换成 `anthropic-messages`；一条路由只能一种协议。
> 用中转站的代价：对话内容会经第三方过一遍，可能有记录/跑路风险，**别发敏感资料，建议小额试用**。

## 四点半、怎么生成发给别人的压缩包

双击 **`打包发布.cmd`**（或运行 `pack-release.ps1`），会在工具包**上一级目录**生成两种包：

| 包 | 大小 | 内容 | 给谁 |
|---|---|---|---|
| `DSH一键安装_发布版_日期.zip` | 约 63 KB / 17 项 | 只含"装完能用"必需：6 个 `.cmd` 入口 + 5 个 `.ps1` 逻辑 + `launcher\` + `assets\dsh.ico` + README + 分发说明 | **发给普通用户**（默认产物） |
| `DSH一键安装_维护版_日期.zip` | 约 93 KB / 36 项 | 发布版全部内容 **+ `tests\` 验收脚本（含 `lnk-verify.ps1`）+ `pack-release.ps1` 打包脚本** | 自己留档 / 交给下一任维护者 |

## 五、给“帮忙装机的人”的技术附录

**命令行参数（install.ps1）**

| 参数 | 作用 |
|---|---|
| `-DryRun` | 只检测不安装（排错首选） |
| `-NonInteractive` | 无人值守，快捷方式用默认名 |
| `-ShortcutName "名字"` / `-IconPath "x.ico"` | 指定快捷方式名称/图标 |
| `-InstallRoot "D:\xxx"` | 指定数据目录（默认自动选非 C 盘最大空间盘） |
| `-SkipNode` / `-SkipDsh` / `-SkipShortcut` / `-SkipDshHome` / `-NoStart` | 分步跳过，便于定位问题 |
| `-Repair` | 修复模式 |
| `-SimulateNoNode` | 测试用：假装没装 Node |
| `-NodeMethod auto\|winget\|portable` | 指定装 Node 的路线：`auto` 默认（winget 优先、失败转免安装版）；`portable` 强制免安装版（免管理员） |
| `-NoEnvChange` | 测试用：不写任何用户环境变量/PATH（隔离验证） |
| `-AppMode on\|off` | 窗口模式：`on` 默认（应用模式 `--app` 独立窗口）；`off` 普通浏览器标签页 |
| `-KillHostOnExit` | 关掉应用窗口时同时停止 DSH 服务（默认否） |
| `-DryRun -SimulateNoNode -NodeMethod portable -NoEnvChange` | 组合起来就是"在隔离目录里真下载 Node 但不碰系统"的验证姿势 |

**命令行参数（launcher\start-dsh.ps1）**

| 参数 | 作用 |
|---|---|
| `-ProbeOnly` | 只判断"复用实例/换端口/直接启动"，不启动任何东西 |
| `-ProbeBrowser` | 只报告会用哪个浏览器、什么模式（测试用） |
| `-NoBrowser` | 启动/复用但不打开窗口 |
| `-NoAppMode` | 本次改用普通浏览器标签页（不改配置） |
| `-KillHostOnExit` | 本次启用"关窗即停服务" |
| `-IsolatedProfile` | 用全新独立的浏览器配置（默认共用你平时的配置，保住界面状态） |
| `-Browser "路径"` | 手动指定浏览器（默认自动找 Edge/Chrome/Brave/Vivaldi） |

```
更新DSH.cmd                      # 交互式

powershell -File update-dsh.ps1 -Restart                             # 更新完自动重启服务
```

**在线装 Node 的两条路线（都不需要梯子）**

| 路线 | 命令/来源 | 说明 |
|---|---|---|
| winget（默认首选） | `winget install OpenJS.NodeJS.LTS` | 系统级安装，会弹一次 UAC；装完在 D 盘（本机 node 在 `D:\Program Files\nodejs`） |
| 免安装版（兜底/免管理员） | npmmirror 国内镜像 `node-v24.x.x-win-x64.zip` | 解压到数据目录、写用户 PATH；**全程不需要管理员权限** |

> 实测（2026-09-15）：免安装路线从镜像下载 Node v24.21.0 → 解压 → `node -v` 校验通过，**全程 47 秒**；隔离模式确认未改动系统 PATH。

**关键设计决策（为什么这么做）**
1. 用**全局安装** `@deepseek-ai/dsh` 而不是每次 `npx`：npx 缓存目录名是哈希（如 `_npx\<一段哈希>`），会变，不能作为快捷方式目标。
2. 桌面路径用 `[Environment]::GetFolderPath('Desktop')`，因为 360/OneDrive 会把桌面搬到 `D:\360MoveData\...`。
3. `.cmd` 入口保持纯 ASCII 并带 `-ExecutionPolicy Bypass`：很多机器默认禁止运行 .ps1。
4. 所有 `.ps1` 存为 **UTF-8 with BOM**，否则 PowerShell 5.1 读中文会乱码/报错。
5. 判断"是否已有 DSH 实例"用 HTTP 探测 + 进程命令行（`bin.js`）双保险，不依赖可能没权限的进程查询。
6. 只保留一个"开页者"：装了 `dsh-web-open` 插件时由插件开页，否则由启动器开页（该插件常通过 `cordis.patch.yml` 插入，检测时要查依赖、bundles、patch 三处）。

**自测**
```powershell
# 离线项（快，约 1.5 分钟）：语法/编码、幂等性、无 Node 分支、端口占用、实例复用、快捷方式、执行策略
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run-all.ps1

# 额外跑“在线装 Node”（真下载约 30 MB，隔离目录，不动系统）
powershell -NoProfile -ExecutionPolicy Bypass -File .\tests\run-all.ps1 -Network
```
